## What Is Bookends for Mac

bookends mac is a full-featured bibliography and reference-management system for macOS from Sonny
Software, built for students, academics and professionals. Rather than scattering PDFs across folders
and typing citations by hand, it keeps your references, attachments, notes and formatting rules in one
searchable library on your own Mac. From there you can search thousands of records, open an article's
PDF instantly, and drop a correctly formatted citation into a manuscript without leaving your writing
app. It is as much a document organizer as a citation tool.

## How the Pieces Fit Together

The strength of bookends for mac is that these features chain into a single workflow. You import a
reference from an online database, and its PDF comes with it; you read and annotate that PDF, and the
notes attach to the record; you cite the record while writing, and the bibliography formats itself. A
capable reference manager mac removes the manual filing between each step, so a library of thousands of
sources stays as navigable as a short reading list.
